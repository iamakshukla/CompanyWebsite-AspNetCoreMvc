# Company Website – ASP.NET Core MVC

A multi-page business/company website built with **ASP.NET Core MVC** on .NET.

## Pages
- Home
- About Us
- Services
- Gallery
- Contact Us

## What this project shows
- MVC pattern: controllers, actions and Razor views
- Conventional routing (`/Guest/Home`, `/Guest/Aboutus`, ...)
- Shared master layout (`_LayoutMaster.cshtml`) with header, navigation menu and footer used by every page
- Static assets (CSS, images) served from `wwwroot`

## Tech stack
- C#, ASP.NET Core MVC
- Razor views, HTML, CSS, Bootstrap

## Run locally
```bash
git clone https://github.com/iamakshukla/CompanyWebsite-AspNetCoreMvc.git
cd CompanyWebsite-AspNetCoreMvc/PracticeWebProjects
dotnet run
```
Then open the URL shown in the console (it starts on the Guest Home page).
